# 空调管路建模工作台

双击根目录 `启动管路工作台.cmd`，或运行：

```powershell
& 'D:\Miniforge3\envs\occ\python.exe' -m pipe_ui.app
```

浏览器打开 `http://127.0.0.1:8765`。所有脚本及三维渲染均在本机，不依赖 CDN。

1. 初始显示环境模型与起终点。当前工作区默认读取 `base/`、`outputs/multi_pipe_config_20261010.json` 和 `outputs/measured_points_20261010.json`。其他工程可通过启动参数 `--config`、`--points`、`--model-dir` 指定输入。
2. “选择环境模型”支持 IGS、STEP、CATPart、CATProduct。CATIA 格式通过现有 `upload.py` 转换到独立输出目录；“读取 CATIA 管路点”从已打开的零件识别完整命名点组。已有同编号配置的挂点归属和双管夹约束会保留。遇到新挂点缺少归属时明确报错，不猜测。
3. 每根管选择工艺表中的管径/材料组合，点击“生成规划”。后台调用现有 `run_multi_pipe`，页面仅显示最终 engineered 曲线。首次模型网格化及规划可能较慢，页面保持任务状态；同一 CAD、端点和规划半径再次生成时会复用已完成的 `planning_space.json`，模型或端点变化后自动重新切片。

命令行也可以用 `--reuse-space-json <path-to-planning_space.json>` 跳过空间重建；该文件旁边必须有本项目生成的 `planning_space.cache.json`，且当前 CAD、端点和空间参数必须匹配。
4. 鼠标悬停切换左侧参数。路径模式下选点并拖动 XYZ 轴，再点“应用微调”；胶管模式下拖动端部改长度，拖动中部沿路线滑动。每端铝套长度固定，胶管中心用距起点的弧长保存。挂点演示按钮不修改任何数据。
5. 每次成功应用微调会另存工程。点击“导出全部 CATPart”会另存路线、检查报告、完整工程和每管一个 CATPart，可通过“打开保存目录”查看。`ui_project.json` 能重新打开；普通 `routes_engineered.json` 需与当前输入管路对应。

顶部显示当前阶段：1 模型与规格 → 2 路径规划 → 3 微调与导出。刷新页面会继续当前服务中的工程。完成规划后，第 1、3 步可往返切换：点击第 1 步会自动保存已应用路线，并仅显示模型与端点；点击第 3 步直接返回已完成结果，无需重新规划。如果在第 1 步改了模型、端点或规格，返回第 3 步恢复的是上次结果及其对应输入；只有点击“重新生成规划”才按新输入计算。旧结果在新规划失败时仍可返回。拖动预览需先应用或取消，才能切换。自动保存工程位于 `outputs/ui/sessions/before_replan_*/`，也可通过“打开已保存工程”恢复。

界面顶部显示实际环境文件名和已记录的点来源；旧工程未记录点来源时明确标为未知。规划时显示实际耗时和规划清单中已记录的当前管路、完成数量，不估算剩余时间。参数默认展示常用项，展开“完整参数与工艺要求”可查看全部条目；规格设置阶段，表格中带输入框的实际/选定、推荐、极限值可直接修改，修改值按管路保存并随下一次规划提交。生成路线后的几何实测值由系统锁定。悬停切换“正在查看”的参数，点击管路才改变“编辑对象”；应用按钮显示具体管号。约束提醒按同类消息聚合，未判定项单独列出，展开后保留所有原始详情。

第 3 步将工程来源折叠为摘要，选择管路和编辑操作保留在参数滚动区之外。选中路线显示独立轮廓，不改变材质颜色或几何数据。警告分组按管路记住展开状态。存在未提交规格或未应用预览时，刷新 / 关闭页面会提示；从修改过规格的第 1 步返回结果或打开另一工程时，也会先提示放弃选择。

工艺条目来源于 `doc/SAAA工艺要求-20260706.xlsx` 的 Sheet1，参数名悬停显示单元格位置。金属/胶管的实测曲率按各自最终材质区间计算。表中 R27.5 与现有 φ19.05 规划执行下限 R28.575 分开显示。齿形、焊点、阀座、铝套背部尺寸、马鞍选型等未提供的数据明确标记，不能据此判定合格。

工艺或碰撞违规保留真实报告并允许导出。未形成工程曲线、固定点被破坏、曲线不连续以及 CATIA 建模/保存失败仍是真实失败。碰撞复核复用当前截面模型及管间包络采样，不代表完整原生 CAD 干涉验收。独立打开没有规划空间的旧结果会明确显示“环境碰撞未重新校核”。CATPart 沿用既有分段圆截面扫掠，不包含新增壁厚、齿形或装配建模。

## 迁移范围

`geometry.py` 的精确曲线、局部变形和双圆弧拟合，`models.py` 的二进制显示网格，`static/viewport.js` 的 WebGL2 渲染以及 `static/interaction.js` 的相机、选点拖动数学，来自用户提供的 `hvwire/pipe-editor管路编辑器是这个！`。已迁移至本包，无运行时参考目录依赖；新增 GUADIAN 固定区、分材质显示和本项目工艺/导出接入。未迁移 PDU 移动、挂点编辑、其他高压线规则。

`hvwire/` 与 `hvwire-route-generation/` 继续由现有 `.gitignore` 排除。
